# 🎨 Kyllian's Neo-Brutalist Portfolio

Welcome to the repository of my 2026 personal portfolio! This project is designed with the bold, high-contrast, and raw aesthetics of **Neo-Brutalism**. It serves as a digital playground to showcase my skills in modern web development, UI/UX design, and creating impactful, non-traditional user experiences.

## 🚀 Tech Stack

- **Core:** React / Vite
- **Language:** TypeScript (`tsconfig.json` optimized)
- **Styling:** Tailwind CSS (Customized for Neo-Brutalist theme - hard shadows, thick borders, vibrant colors)
- **Package Manager:** npm

## ✨ Key Features & Architecture

- **Neo-Brutalist UI:** Breaking the rules of modern flat design with bold typography, distinct borders, and raw elements.
- **Blazing Fast Performance:** Powered by Vite for instant server start and lightning-fast Hot Module Replacement (HMR).
- **Type-Safe Ecosystem:** Strictly written in TypeScript to ensure code quality, predictable behaviors, and easy maintainability.
- **Fully Responsive:** Fluid layouts that adapt seamlessly across mobile, tablet, and desktop environments.

## 🛠️ Getting Started

Follow these steps to set up and run the project locally on your machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kylliankoniz/Kyllian-neobrutalist-portfolio-2026.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Kyllian-neobrutalist-portfolio-2026
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```
   *(Note: This project uses `npm` as the primary package manager. Please avoid using `bun` or `yarn` to prevent lockfile conflicts).*

4. **Environment Variables:**
   Copy the example environment file and update the values if necessary:
   ```bash
   cp .env.example .env
   ```

5. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open your browser and visit `http://localhost:5173` to see the app live!
